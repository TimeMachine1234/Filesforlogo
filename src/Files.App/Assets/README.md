# Assets

This folder contains all logo, SVG, and image files used by the Files app.

## Folder Structure

| Folder / File | Description |
|---|---|
| `Icons/` | Folder icon images used throughout the app (`FolderIcon.png`, `FolderIcon.svg`, `FolderIcon2.svg`) |
| `FluentIcons/` | Fluent UI icon PNGs (CloudDrive, FileTags, Home, Star) |
| `WSL/` | Linux distribution icons (SVG and PNG) for Windows Subsystem for Linux |
| `Shelf/` | SVG images for the empty shelf state (light/dark themes, multiple sizes) |
| `Sidebar/` | SVG images for the empty sidebar state (light/dark themes, multiple sizes) |
| `Archives/` | Extension icons for archive file types |
| `Resources/` | JSON resource files (properties information) |
| `Libraries/` | WinMD and NuGet package files used at build time |
| `FilesOpenDialog/` | Assets for the open/save dialog integration |
| `error.png` | Error notification icon |
| `tile-0-250x250.png`, `tile-0-300x300.png` | Start menu tile images |

> **App tile logos** (splash screen, Square44x44, Square150x150, etc.) are located in  
> `src/Files.App (Package)/Assets/AppTiles/` under `Dev/`, `Preview/`, and `Release/` subdirectories.
